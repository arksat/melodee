シーケンサー操作早見表

Melodee 1.1.0 向け。ブラウザを閉じても読める単一ファイル版です。

ノート編集録音パターンソング音色選択取り消し
いちばん大事：ノート編集は SEQ → NOTES。消したいノートを KNOB 1 で選び、EDIT を短く押します。

ノート編集：SEQ → NOTES

SEQ を押して NOTES ページを開きます。もう一度押すと PATTERNS、TEMPO などのシーケンサー・ページへ移ります。ピアノロール上の明るい枠が選択ノート、縦の動く線が再生位置です。

操作結果
KNOB 1 STEPノート／空ステップを前後に選択。コードは各ピッチを個別に選べます。
KNOB 2 PITCH選択ノートの音程を変更。空の手入力ステップではノートを追加します。
鍵盤または MIDI空のステップにノート／コードを入力。演奏録音では通常どおり録音します。
KNOB 3 LENGTHノート長を変更。ENV を押しながら回すと 1/16 ステップ単位で微調整。
KNOB 4 VELベロシティを 1〜127 に変更。ENV＋KNOB 4 で手入力ノートの Slide を切替。
PRESETS選択位置の表示倍率を 16 ステップ〜1ステップに変更。
OCT+空白ならノート／ドラムヒットを置く。ノート選択中なら詳細（Length / Velocity / Chance / Slide / Delete）を開く。
OCT−詳細を閉じる／前の画面へ戻る。シンセのステップ編集中はカーソル移動にも使えます。

削除・移動・伸縮

  • 1音だけ削除：KNOB 1 で対象を選択 → EDIT を短く1回押す。コードは選択中のピッチだけ消え、最後の1音を消すとタイも消えます。
  • 詳細から削除：対象を選択 → OCT+ → Delete。
  • 位置を移動：SCL を押しながら SELECT または KNOB 1。
  • 長さを変更：ENV を押しながら SELECT または KNOB 1。
注意：EDIT を押したまま他の操作をすると「削除タップ」として扱われません。削除は単独で短く押してください。

ライブ録音と消去

  • 録音開始：対象トラックを選び、REC＋PLAY。REC 単独は録音待機の切替です。
  • 演奏の後追い記録（Capture）：再生中に REC を長押し。選択トラックで直近に弾いた内容をパターンへ書き込みます。
  • 再生しながら消去：選択トラックが録音中かつ再生中に、EDIT を押し続ける。再生ヘッドが通るノート、ドラム、タイを消去します。
ライブ消去は通常の8段階 Undo では戻せません。必要なら先にプロジェクトを保存してください。

録音したノートも NOTES で個別選択・音程・長さ・ベロシティ編集・削除ができます。停止してから編集するのが安全です。タイミングを揃えたい場合は SEQ → TEMPO → QNT。OFF に戻すと元の演奏タイミングで鳴ります。

パターン（1〜8）

  • パターンを選ぶ：SEQ を押しながら最初の8つの白鍵。再生中ならトラックごとにループ終端で切り替わります。
  • 一覧を開く：SEQ → PATTERNS、または SEQ 長押し。
  • パターンの複製：一覧で対象トラックのパターンを選択 → OCT+ → Copy to… → ノブで空き先を選び OCT+。使用済みスロットへの上書きは確認が出ます。
  • パターン全消去：同じシートの Delete pattern。ノートとモーションも消えます。直後なら SAVE 長押しで戻せます。

ソング構成

SEQ → SONG。KNOB 1＝セクション、KNOB 2＝トラック、KNOB 3＝そのトラックのパターン、KNOB 4＝繰り返し回数（1〜16）。最大16行です。

Jam から曲にする：再生後のパターン切替はログに残ります。SONG ページで REC を長押しすると、その Jam をアレンジメントに変換します。

音色選択：SAVE → PRESETS

  1. まず ALGORITHM で対象トラック（T1〜T4）を選びます。
  2. SAVE を押してから PRESETS を選び、音色ブラウザーを開きます。PRESETS ノブを回すだけでは開きません。
  3. KNOB 1 でリストを選択：各音源の Factory、Native User、一般 User、FAV、RECENT、またはカテゴリ。
  4. KNOB 2 で音色を選択します。候補を素早く回した時は、ノブを止めた時点で読み込まれます。
操作結果
KNOB 4音源を切替（PROPHET / FM6 / CZ-1 / SID / DRUM）。切替直後は各音源の INIT 音色から開始。
SAVE 長押しブラウズ前に使っていた音色へ戻る。
OCT+ 長押し選択音色のシートを開く。Init sound を選べばそのトラックの音源を初期化。

カテゴリは BASS / LEAD / PAD / KEYS / ORGAN / STRING / BRASS / WIND / PLUCK / BELL / DRUM / FX / OTHER。FAV はお気に入り、RECENT は電源投入後に開いた音色の履歴です。

取り消しと保存

  • ノート編集を戻す：SAVE 長押し。長押し中に OCT−＝Undo、OCT+＝Redo。最大8編集。
  • プロジェクト保存：SAVE＋REC。再生は停止して保存されます。
  • オートセーブ：保存先スロットのあるプロジェクトは、停止して5秒無操作で自動保存。
